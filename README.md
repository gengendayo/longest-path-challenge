# 最長片道きっぷの旅 (Longest Path Challenge)

株式会社ドリーム・アーツ 2027年新卒 エンジニア採用コーディングテストの提出コードです。

## 前提条件・仕様の解釈について
課題の入力フォーマットには「始点・終点」の記述がありましたが、対象が鉄道路線網であること、および「同じ点を2回通らない（片道きっぷ）」というルール設定から、各路線は双方向に移動可能な「無向グラフ」であると推測し、実装を行いました。

## 開発・動作環境
* OS: Windows 11 / Linux (x86_64)
* 言語: Go (Version 1.22 以降 / 動作確認環境: 1.26.5)

## 実行手順 (Linux / クロスプラットフォーム)

### 1. ビルド方法
Goがインストールされた環境で、以下のコマンドを実行しバイナリを作成します。

```bash
# Linux (x86_64) 向けにクロスコンパイルする場合
